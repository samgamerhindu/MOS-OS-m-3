One board. Four souls.

M³-OS (MOS) is an upcoming open-source operating system architecture designed to give ESP32 hardware modular personalities: MOS-Core, MOS-LCD, MOS-OLED, and MOS-Hack.

Planned OS Variants

Explore the four modular personalities conceptualized for the M³-OS ecosystem.

Python RTOS In Design

MOS-Core

Real-Time MicroPython OS

Combines Python ease-of-use with preemptive multitasking and a Zephyr-like kernel API.

Preemptive Scheduler Concept
Threads, Queues & Semaphores
Asyncio + _thread support
Target: ~1.2 MB
GUI Engine In Design

MOS-LCD

GUI Touchscreen OS

Build interactive touchscreen UIs with customizable app extensions, themes, and backgrounds.

ILI9341 & ST7789 Drivers
Dynamic App Engine
Customizable Layouts & Icons
Target: ~2.1 MB
Monochrome UI In Design

MOS-OLED

Sub-Variant for SSD1306

Ultra-lightweight monochrome micro-OS optimized for 0.96" and 1.3" I2C OLED screens with high FPS.

Direct I2C Frame Buffer
Ultra Low RAM Footprint
Compact Menu & Widgets
Target: ~600 KB
Native Pentest In Design

MOS-Hack

Native C/C++ Security Suite

Low-level raw packet injection, Bluetooth scanning, and USB HID ducky script payloads.

802.11 Deauth & PMKID
BadUSB Keyboard Injection
Sub-GHz Hardware Support
Target: ~3.4 MB
